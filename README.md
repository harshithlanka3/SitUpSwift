# SitUpSwift

SitUpSwift is an iOS posture-tracking app built on MediaPipe Pose Landmarker. It uses the camera to detect body landmarks in real time, classifies posture (good posture, L-posture, and T-posture), and stores session/frame data in Firebase Firestore. The app also includes a simple username/password authentication flow.

## How to Run

1. Install dependencies:
   ```bash
   pod install
   ```
2. Set up Firebase:
   - Create a Firebase project and iOS app.
   - Add `GoogleService-Info.plist` to the `PoseLandmarker` target.
3. Configure `HASH_SALT_KEY` in `PoseLandmarker/Info.plist` with a secure random value (required for credential hashing).
4. Open the project in Xcode (use the workspace generated by CocoaPods after step 1).
5. Select an iOS simulator or device, then build and run.

For full Firebase configuration details, see `FIREBASE_SETUP.md`.
